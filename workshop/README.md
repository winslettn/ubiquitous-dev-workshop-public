# Workshop Guide

This repository  uses a single `workshop/` folder with one shared setup module and three module groups aligned to products (GitHub Enterprise, GitHub Copilot, and GitHub Advanced Security and Code Quality).

## Start here

1. Complete shared setup: [m00-setup.md](m00-setup.md) (90 min)
2. Follow modules in numeric order by group, as directed by your instructor.

## Modules 10+: Development Platform

**Duration:** ~6 hours (including setup)  
**Skill level:** Beginner to Intermediate

- m10 GHE Admin *(admin audience; instructor pack: `docs/.instructor/m10-ghe-admin/`)*
- [m11-ghe-basics.md](m11-ghe-basics.md) *(optional)*
- [m12-agents-orchestration.md](m12-agents-orchestration.md)
- [m13-actions-automation.md](m13-actions-automation.md)
- [m14-code-security.md](m14-code-security.md) *(optional)*
- [m15-waf.md](m15-waf.md) *(optional)*
