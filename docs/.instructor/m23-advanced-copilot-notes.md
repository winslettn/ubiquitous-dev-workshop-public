# M23 Advanced GitHub Copilot - Instructor Materials

Use this module as the instructor facilitation guide.

## Preparation

### Delivery priorities

1. Present the module topics in the exact sequence defined in metadata.
2. Keep explanations aligned to participant outcomes and practical application.
3. Reserve enough time for all lab exercises from the related workshop module.

### Demo preparation

- Review the related workshop module: `m23-advanced-copilot.md`.
- Confirm links, environments, and permissions needed for demonstrations.
- Prepare one concise transition from presentation topics to hands-on work.

### Success signal

Participants can explain the core module topics and complete the mapped lab exercises with minimal prompting.

---

## Presentation

Duration: 30 min. instruction

- Harnesses: CLI, GitHub Copilot App, ...
- Custom instructions and AGENTS.md design
- Skills and slash-command workflows
- MCP integrations for external systems
- Copilot Spaces and institutional knowledge workflows
- Custom agents, SDK/extensions, and when to build vs configure
- Planning mode for complex tasks
- Advanced multi-file refactoring patterns

---

## Lab Exercises

Duration: 75 min. hands-on

1. Exercise 1: Compare advanced Copilot harnesses for one scoped task
2. Exercise 2: Design repository-level custom instructions and `AGENTS.md` guardrails
3. Exercise 3: Build a skill and slash-command workflow for repeat tasks
4. Exercise 4: Connect external context with MCP safely
5. Exercise 5: Use planning mode for complex, staged execution
6. Exercise 6: Execute an advanced multi-file refactor with guardrails

---

## Wrap-up

Summarize key decisions, outcomes, and follow-up actions before moving to the next module.
