## The Idea-to-Code Cycle

<!--
layout: content
-->

Five stages:

1. **Ideation** — Requirement or user story in
2. **Planning** — Tasks and acceptance criteria out
3. **Scaffolding** — Project structure and interfaces
4. **Implementation** — Feature code, tests, docs
5. **Review** — Quality, security, coverage

```speaker-notes
Each of these maps to a specific Copilot capability participants will learn in upcoming modules. This slide is a roadmap for the rest of the day.
```

## Where Copilot Fits

<!--
layout: table
-->

| Stage | Copilot Feature |
|---|---|
| Ideation | Copilot Chat, Workspace |
| Planning | Copilot Agent, issue decomposition |
| Scaffolding | Code generation, custom instructions |
| Implementation | Inline completions, agents |
| Review | Code review, test generation |
