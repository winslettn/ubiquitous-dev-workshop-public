# Getting Started

Use this page as the quick navigation guide for the training repository.

## Choose your role

- **Participant**: start with `modules/m00-environment-setup/README.md`
- **Instructor**: start with `docs/.instructor/INSTRUCTOR_GUIDE.md`

## Choose your track

Pick one language and one IDE for your workshop run:

- Languages: Python, TypeScript, C#, Java
- IDEs: VS Code, Visual Studio, JetBrains, Eclipse, Vim/Neovim

You do not need to install every language runtime or every IDE.

## Quick workflow

1. Complete Module 00 prerequisites for your chosen track.
2. Complete Module 01 Copilot onboarding for your IDE.
3. Continue through modules in order (`m02` through `m14`) or select a focused
   path based on your goals.

## Useful locations

- Participant modules: `modules/mNN-*/README.md`
- Instructor assets: `docs/.instructor/mNN-*/`
- Shared app implementations: `src/python`, `src/typescript`, `src/csharp`, `src/java`
- Module standards: `docs/MODULE_GUIDE.md`
- Validation notes: `docs/M01-M03-VALIDATION.md`
